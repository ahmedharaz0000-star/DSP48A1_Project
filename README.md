# DSP Project

## Description
This project is a Digital Signal Processing (DSP) simulation project.

## Project Contents
- Verilog source files
- Testbench files
- Simulation scripts
- ModelSim simulation files
- Project screenshots

## Tools Used
- Verilog HDL
- ModelSim
- Digital Signal Processing concepts

## How to Run
1. Open the project in ModelSim.
2. Compile the Verilog source files.
3. Compile the testbench.
4. Run the simulation using the provided `run.do` script.
5. Observe the simulation results.

## Files
- `tb_DSP48A1.v` — Testbench file.
- `run.do` — Simulation script.
- `transcript` — Simulation transcript.
- `vsim.wlf` — ModelSim waveform file.
